Alexa Shopping Suppressor for Amazon

Open-source Manifest V3 Chrome extension that suppresses Amazon's Alexa for Shopping / Rufus interface and repairs the blank docked-sidebar gutter.

The extension runs locally, has no analytics or telemetry, makes no network requests, stores no user data, and requests no privileged Chrome API permissions.
