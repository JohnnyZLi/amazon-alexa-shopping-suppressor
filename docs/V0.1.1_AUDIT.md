# v0.1.1 security audit record

On September 3, 2026, v0.1.1 was re-audited after the initial working v0.1.0 baseline.

The review confirmed the extension's least-privilege design and drove two hardening changes:

- content-script execution was narrowed to exact HTTPS Amazon retail hosts instead of wildcard Amazon subdomains;
- broad Rufus/Alexa selectors were moved behind fail-open JavaScript validation instead of unconditional CSS suppression.

The resulting v0.1.1 commit remains in history as the security-hardened baseline before the later v0.2.0 release-candidate work.
