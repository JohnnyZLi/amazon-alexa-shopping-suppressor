Privacy Policy

Alexa Shopping Suppressor for Amazon

This extension does not collect, transmit, sell, or share personal data, browsing history, Amazon account information, purchase information, or page contents.

Local page processing

The extension reads and modifies DOM information on supported Amazon retail pages only to identify Alexa for Shopping / Rufus interface elements, suppress them, and repair related docked layout state. This processing occurs locally in the browser.

Local On/Off preference

The extension stores exactly one local preference using chrome.storage.local: a boolean named enabled that remembers whether the suppressor is On or Off. This setting is not derived from Amazon page content and is never transmitted anywhere. It remains until the user changes it, clears extension data, or removes the extension.

No telemetry or remote communication

The extension contains no analytics or telemetry, makes no network requests, uses no remote code or remote dependencies, and does not send page information or the On/Off preference to the developer or any third party.

Other storage

The extension does not use localStorage, sessionStorage, IndexedDB, page cookies, or another persistence mechanism for Amazon data.

Permissions

The extension requests exactly one Chrome API permission: storage, used only for the local On/Off preference. It does not request tabs, scripting, activeTab, history, downloads, cookies, webRequest, or background permissions. Its site access is limited by the manifest to explicitly listed Amazon retail storefronts over HTTPS.

Open source

The extension source code and security documentation are publicly available in the project repository, allowing users to inspect the exact behavior of each release.

Changes

If the extension's data handling changes in a future release, this policy and the Chrome Web Store disclosures will be updated before that release is published.
