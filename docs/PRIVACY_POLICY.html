Privacy Policy

Alexa Shopping Suppressor for Amazon

This extension does not collect, store, transmit, sell, or share personal data, browsing history, Amazon account information, purchase information, or page contents.

Local page processing

The extension reads and modifies DOM information on supported Amazon retail pages only to identify Alexa for Shopping / Rufus interface elements, suppress them, and repair related docked layout state. This processing occurs locally in the browser.

No telemetry or remote communication

The extension contains no analytics or telemetry, makes no network requests, uses no remote code or remote dependencies, and does not send page information to the developer or any third party.

No persistent extension data

The extension does not use Chrome extension storage, localStorage, sessionStorage, IndexedDB, cookies, or another persistence mechanism.

Permissions

The extension requests no privileged Chrome API permissions. Its site access is limited by the manifest to explicitly listed Amazon retail storefronts over HTTPS.

Open source

The extension source code and security documentation are publicly available in the project repository, allowing users to inspect the exact behavior of each release.

Changes

If the extension's data handling changes in a future release, this policy and the Chrome Web Store disclosures will be updated before that release is published.
